# Homepage image provenance

The photographs in this directory were extracted from the user-supplied Theos website flow PDF. Gallery images retain their original marks and are visual references, not verified Theos client projects. Four depth maps were prepared with Magnific for the opening scenes. The architectural image supplies the aligned sketch/form/colour treatment. The spiral reference is a fallback; the live spiral is procedural Three.js geometry.

Original reference documents remain in the local cleanup recovery archive. Detailed mapping is recorded in the redesign documents under `docs/`.
