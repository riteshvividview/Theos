## Proposed first-section animation flow

Start with the exact rhino/ivory/red composition and framed navigation. Establish the image before the two editorial lines enter with short, staggered masked movement. Use low-amplitude depth parallax: ground/furniture, red figure, rhino and sky have different responses, while the camera remains composed. Typography remains separate and sharp.

Scroll holds one full-screen stage and advances a single master timeline. Each world has a readable hold, a purposeful push toward an art-directed detail, an expanding image/color aperture that takes over the screen, then a settling reveal into the next world. Sequence: rhino lounge -> eye-relief interior -> cobalt bedroom/heart -> reflective pool with blue spheres. Candidate handoffs are rhino eye/ivory relief, red accent to red heart, and cobalt upholstery to blue spheres. These targets are proposed, not literal fully specified PDF instructions.

Use the circular expansion observed in pin 667799451022626708, depth layering from 550213279488808195/397513104611621182, and subject-led continuity from 591871576022028979. Avoid adding fire/burn/particle effects merely because the older creative notes mentioned them. Shader work should perform precise masks, depth displacement and transition continuity rather than distort furniture or faces. The transition must reverse cleanly with scroll; a static reduced-motion view and intentional mobile framing are required.

## Asset strategy and technical fit

- Extracted original PDF scene images are available without overlaid navigation/text. Verified first image visually. Hero sources are 1672x1077 JPEGs. Use these as composition anchors; an aggressive zoom needs careful upscaling/detail or a matched close-up, not stretching a screenshot.
- Image-first: preserve reference composition. Magnific can upscale, produce depth maps, segment masks and prepare background plates; regenerate only when necessary, using the reference rather than a loose text-only prompt. Its relevant tools are discoverable; no generation/upload/credit spend was performed.
- Small real 3D where it contributes: timeline ribbon, brand O/star or a precisely matched object. Blender/Sketchfab can support this later; no model downloaded, Blender scene changed or live connection verified in this study.
- Layer separation requires filled background behind foreground cutouts; avoid parallax tears/halos. Bound movement to what the image supports. Generated video may support internal motion, but should not drift furniture/face identity. Match first/last transition frames.
- Keep installed React/TypeScript/Vite, Three.js/R3F/Drei, GSAP/ScrollTrigger, Lenis, postprocessing and Tailwind. Current package and `src/hooks/useSmoothScroll.ts` inspected: one GSAP ticker drives Lenis. Reuse it; do not add a competing scroll loop.
- Existing `src/pages/Home.tsx` still composes rejected cloud/gallery/royal journey. No code altered. Before implementing, snapshot relevant source/assets; this folder is not currently a Git repository, so do not assume Git rollback exists.
- Final navigation names, milestone copy, testimonials and project footage remain content dependencies. They do not block building the first hero scene from supplied imagery.
